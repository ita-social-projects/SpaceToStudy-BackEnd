# Вказівки щодо внесків 🛠️

## Крок 1: Знайдіть задачу

Перевірте [відкриті завдання](../../issues) у головному репозиторії та оберіть те, над яким хочете працювати.  
Або створіть нове, якщо виявили помилку або маєте ідею для нового функціоналу.

## Крок 2: Форкніть репозиторій 🍴

Натисніть кнопку **"Fork"** у правому верхньому куті сторінки репозиторію, щоб створити його копію у своєму акаунті GitHub.

## Крок 3: Клонуйте репозиторій 🌿

Скористайтеся HTTPS або SSH для локального клонування:

```bash
git clone https://github.com/your-username/your-fork.git
cd your-fork
```

## Крок 4: Підготуйте середовище

Перейдіть на гілку розробки:

```bash
git checkout develop
```

Встановіть залежності:

```bash
npm ci
```

Створіть нову гілку:

```bash
git checkout -b your-branch-name
```

> 💡 Використовуйте осмислені назви гілок, наприклад: `fix/footer-bug` або `feature/add-ua-localization`.

Налаштуйте змінні середовища у файлі `.env`.

## Крок 5: Виконуйте завдання 👨‍💻👩‍💻

Внесіть необхідні зміни в код або документацію.  
За потреби запустіть [Back-end репозиторій](https://github.com/ita-social-projects/SpaceToStudy-BackEnd).

## Крок 6: Протестуйте зміни

Переконайтесь, що все працює у вашому локальному середовищі.

## Крок 7: Зробіть коміт ✅

Додайте зміни та створіть коміт:

```bash
git add .
git commit -m "feat: описова назва коміту"
```

> ✏️ Бажано використовувати [conventional commits](https://www.conventionalcommits.org/).

Перед Pull Request'ом об'єднайте кілька комітів у один (squash).

## Крок 8: Відправте зміни 🌍

```bash
git push -u origin your-branch-name
```

## Крок 9: Створіть Pull Request ➡️

- Перейдіть на сторінку вашого форку на GitHub
- Натисніть **"New Pull Request"**
- Виберіть базову гілку `develop`
- Перевірте зміни та натисніть **"Create Pull Request"**
